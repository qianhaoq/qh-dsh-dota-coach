# 架构与知识治理

## 组件

- `packages/coach/src/index.ts`：Cordis 生命周期、正式工具和生成的 Typert Remote。
- `service.ts`：唯一领域服务，面板与工具共用；不包含聊天后端。
- `store.ts`：Node SQLite、FTS、证据与训练事务、幂等迁移、索引队列。
- `memory.ts` / `memory-worker.ts`：MemOS 公共核心；worker 隔离模型桥、原生库与长期任务。
- `http.ts` / `replay.ts` / `tasks.ts`：并发合并、响应头限速、原子下载、子进程与取消。
- `src/client`：React 18 四页、宿主插槽、工具卡片和会话草稿；无数据库、文件或 OpenDota 直接访问。
- `go`：manta 固定节奏实体采样、眼位生命周期与建筑身份；内置 dem/bz2/zstd 解码。

部分原型展示纯函数保留在 `src/legacy`，由固定 fixtures 回归验证；宿主、客户端和新领域逻辑使用 strict TypeScript。

## 知识分层

原始来源、可读取正文、原文定位和 SHA-256 是证据层。知识条目引用它们，保存类别、补丁和复检标记。复盘引用来源或比赛快照，并保留学员解释和唯一训练规则。训练记录保存后续比赛与用户自报执行。

`dota_kb search/get/status` 是 DSH agent 的本地知识读取入口，直接按 `##` 分节读取 data home 中的 `principles.md`（稳定原理）、`library.md`（版本事实/反例），并合并 SQLite note/FTS；写入和修订仍用 `dota_coach_note`。版本资料约定为 `patch/<ver>/heroes/<hero>/*.md`，只创建空 `patch/`，不生成知识；stamp 用 `[版本 · 日期 · 来源]`，缺失 stamp 的事实保留并标记待复检，已有 stamp 也不代表独立验证。比赛 ID 的教练循环是 OpenDota `dota_match` 事实 → `dota_kb search` 知识 → 引用 stamp 与证据等级推理；热度不能推导因果建议。DSH 是基座，未来薄站仅读取 export/site，本次不实现站点；dem 和 cookies 仅留本地，不做云同步。

MemOS 是这些记录的检索与候选经验层。投影队列与记录在同一 SQLite 事务中写入；确认仅在内容哈希仍相同时生效。旧版本投影不会被当作当前证据返回。长文本按字符分块并保留重叠、原始记录 ID 与块位置；原文不被索引替代。

重新读取来源时，工具可分页；原始哈希针对完整正文。对局 API 的采集时间来自缓存条目，不能把缓存读取时间充作重新采集时间。

## 学习规则

学习在明确的 `dota_memory learn` 调用中执行，绑定到调用它的 DSH 模型路由。没有路由时拒绝执行归纳。公开材料导入和机械索引无需模型调用。Worker 不读取 DSH 密钥；辅助调用经宿主 LLM 服务完成。

每条复盘的学习幂等。显式学习会为新记忆生成本地向量；离线模型缺失时保留文本，可在模型就绪后更新索引。MemOS 归纳阈值要求多条独立复盘，生成的策略、世界模型和技能仍以候选经验展示。用户需要回到原文或比赛证据确认适用性；采用新结论时保存知识修订，旧条目保留替代关系。库内部的排序、价值和置信度不是学员成长分。

明确区分：材料支持、独立验证、版本适用性和用户自报。传入新证据不会使未知补丁变成当前版本；导入评论不能升级为事实来源。检索结果作为数据，不能控制工具、覆盖技能指令或自行部署新技能。

## 生命周期与失败

插件卸载先拒绝新调用，取消任务并等待在途调用，随后关闭 MemOS worker 和 SQLite。一个共享请求的调用者取消不会取消其他调用者；最后一个任务等待者取消会中止该任务。子进程退出后才完成清理。

录像先下载到临时文件，校验长度和哈希，再由 Go 解码到暂存目录；完整成功后提交 ready manifest。失败、取消或超时清理暂存数据。限速、文件超限、不可用录像、缺失数据和校准失败均可独立识别。

轨迹时钟是 demo tick / 30。只以相同建筑标识校准；无法识别建筑或存在歧义时不做时间猜测。Hero 身份通过 PlayerResource 的选中句柄与实体 serial 配对，复制体不与主英雄轨迹混合。原始轨迹保留 Source 2 的生命状态枚举；公开位置结果另给 `life_state` 和明确的 `alive: boolean | null`，避免把 0（存活）误读为 false。眼位缺少删除记录时不编造寿命。

## 兼容与打包

MemOS 2.0.21 的旧 DSH 适配器仍声明较旧的 peer 范围。本插件使用公共 MemoryCore，通过自己的当前 DSH 桥接层集成，独立验证读写、检索、重载与关闭。运行依赖和对应平台二进制随 `.tgz` 分发，保持新机器可安装性。

DSH Typert 生成器按工作区包识别协议符号。构建把已安装公开协议声明原样暂存为工作区输入，再使用官方 Analyzer 和 Emitter 生成 Host/Remote。临时声明不修改 SDK，也不进入发布物。客户端工厂按 `window.__ModuleLoader__.load` 格式构建，React 和客户端 store 使用宿主提供的实例。

项目不修改 `dota2.ai`，不发布 npm/插件市场，不增加云同步或定时自动学习。
